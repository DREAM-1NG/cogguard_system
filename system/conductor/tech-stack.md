# Technology Stack

- Frontend: Vue 3, TypeScript, Vue Router, Pinia, Ant Design Vue, ECharts, Vite; 3D Force Graph with Three.js for coordination networks.
- Backend: FastAPI v1/v2 APIs, SQLAlchemy, MongoDB event data, NetworkX propagation graphs.
- Propagation graph rendering consumes backend summary nodes and evidence edges; no frontend dependency is added for role overviews.
