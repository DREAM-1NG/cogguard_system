Social bot detection
The emergence of AI-driven social bots that manipulate public opin-
ion necessitates effective detection mechanisms to distinguish them
from human accounts. Social bot detection is a binary classification
problem where the bot label 𝑦𝑈∈{0, 1} indicates a bot user (1) or
a human user (0). Current social bot detection tasks are categorized
into three types based on input data: user-based, content-based, and
graph-based detection [17]. User-based bot detection extracts
features from user profiles and numerical or categorical data, em-
ploying traditional classifiers to identify bots [17]. Content-based
bot detection analyzes post content using NLP techniques, such
as word embedding and RNN, on users’ posts and descriptions [18].
Graph-based bot detection examines the user relationship struc-
ture within a social network 𝐺𝑆, applying network analysis tech-
niques to differentiate between bots and humans [17].
4.1
Definition.
In light of the symbol definitions provided in the previous sections,
user-based, content-based and graph-based bot detection can be
defined as follows, respectively.
• User-based bot detection: Given the labeled user set 𝑈with user
information, user-based bot detection aims to learn a classifier
𝑓: 𝑓(𝑈) →𝑦𝑈that can detect a user’s bot label 𝑦𝑈.
• Content-based bot detection: Given the labeled user set 𝑈with
user information and the post set 𝑝with the post content, content-
based bot detection aims to learn a classifier 𝑓: 𝑓(𝑈, 𝑃) →𝑦𝑈
that can automatically detect the bot label 𝑦𝑈for a user 𝑢.
• Graph-based bot detection: Given the labeled user set 𝑈with user
information and the social network 𝐺𝑆= {𝑉𝑈, 𝐸𝑆}, graph-based
bot detection aims to learn a classifier 𝑓: 𝑓(𝐺𝑆) →𝑦𝑈that can
automatically detect the bot label 𝑦𝑈for a user 𝑢.
